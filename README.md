# 英語学習アプリ

レベルと興味に合わせて、単語・文法・長文読解の教材を自動で用意する英語学習アプリです。スマホのホーム画面に追加するとアプリとして起動します (PWA)。

## 3つの機能

### 単語学習
- 最初の10問であなたの単語レベル (A1〜C1) を測定します。正解すると次は難しい単語、間違えると易しい単語が出る階段方式です
- 出題は3択の自己判定 (知っている / 知っているか怪しい / 知らない)。「怪しい」を選んだときだけ4択で意味を確認します
- 直近20問の正解率が85%以上ならレベルが1段上がり、50%以下なら1段下がります
- 間違いが多い単語ほど頻繁に出題されます。「知っている」を既定3回選んだ単語は出題から外れ、最終正解から既定30日が経つと再び出てきます (しきい値は設定タブで変更できます)
- 間違えた単語だけを解き直す苦手演習モードがあります

### 文法学習
- 12トピック (時制・助動詞・受動態・不定詞・分詞・関係詞・比較・仮定法・前置詞・接続詞・冠詞・語法) の4択問題
- トピック別の正答率を記録し、正答率60%未満の苦手トピックを「おまかせ」出題で優先します
- 未出題の問題が優先的に出ます

### 長文読解
- あなたの興味テーマとレベルに合わせた英文をその場で生成します
- 単語学習で間違えた単語が本文に織り込まれ、ハイライト表示されます
- 語注・全文和訳・内容理解の4択問題つき

学習記録はブラウザのローカルストレージに保存されます (サーバーには送信されません)。

## セットアップ

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY を記入 (長文読解のみで使用)
npm run dev
```

http://localhost:3000 を開きます。

単語と文法は `public/english-words/` `public/english-grammar/` の事前生成データベース (単語1,213語・文法598問) を使うため、APIキーなしでも動きます。長文読解だけがAPIキーを必要とします。

### データベースを作り直す

```bash
npm run gen:words     # public/english-words/{A1..C1}.json
npm run gen:grammar   # public/english-grammar/{A1..C1}.json
```

どちらも Claude API を使うため `.env.local` の `ANTHROPIC_API_KEY` が必要です。生成には10分ほどかかります。

## デプロイ

Vercel にそのままデプロイできます。環境変数 `ANTHROPIC_API_KEY` を設定してください。

> 公開URLで長文読解を使うと、利用者ぶんのAPI料金がキーの持ち主に請求されます。不特定多数に公開する場合は注意してください。
