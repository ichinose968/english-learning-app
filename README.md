# 英語学習アプリ

レベルと興味に合わせて、単語・文法・長文読解・AI会話の教材を自動で用意する英語学習アプリです。スマホでの利用を前提に作っています。ホーム画面に追加するとアプリとして起動します (PWA)。

## 機能

### 単語 (カード)
- 最初の10問で単語レベル (A1〜C1) を測定します。正解すると次は難しい単語、間違えると易しい単語が出る階段方式です
- カードをスワイプして自己判定します。右 (○ Mastered) / 左 (× New) / 上 (? Fuzzy)。「?」を選んだときだけ4択で意味を確認します
- 直近20問の正解率が85%以上ならレベルが1段上がり、50%以下なら1段下がります
- 上部タブで出題範囲を切り替えられます (ランダム / 要復習 / 未学習 / 学習中 / 学習済み)
- ○ が既定3回**連続**した単語は「学習済み」として出題から外れます。初見で ○ を選んだ単語は「既知」として除外します
- カード詳細では意味・タグ・例文・派生語・メモを編集でき、背景画像も設定できます。ステータスの手動変更も可能です

### 単語リスト
- 全単語をNotion風のテーブルで一覧できます。複数条件のソート・フィルタ・検索に対応
- 行をタップするとカード詳細が開きます

### 文法
- 12トピック (時制・助動詞・受動態・不定詞・分詞・関係詞・比較・仮定法・前置詞・接続詞・冠詞・語法) の4択問題を無限に出題します
- トピックは複数選択できます。おまかせでは正答率60%以下の苦手トピックを優先します
- 出題難易度 (レベル) も複数選択できます

### 読解
- テーマ・難易度・長さ・勉強目的を指定して英文をその場で生成します
- 学習中・要復習の単語が本文に織り込まれ、ハイライト表示されます。タップすると単語詳細が開きます
- 語注・全文和訳・内容理解の4択問題つき。全問選んでから「解答を確認」でまとめて採点します

### AI会話
- AIとテキストでチャットできます。レベル・会話量・トピックを設定できます
- 添削をオンにすると、AIの返信の前に「メッセージ添削」が入り、送った英文を直してくれます
- ボイス会話は未実装です

学習記録はブラウザのローカルストレージに保存されます (サーバーには送信されません)。

## セットアップ

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY を記入
npm run dev
```

http://localhost:3000 を開きます。

単語・イディオム・文法は `public/` 以下の事前生成データベース (語彙6,020語・イディオム1,614語・文法2,987問) を使うため、APIキーなしでも動きます。**読解とAI会話だけ**がAPIキーを必要とします。

### データベースを作り直す

```bash
node scripts/generate-english-words.mjs
node scripts/generate-english-grammar.mjs
node scripts/merge-english-db.mjs words   # words | idioms | grammar
```

どちらも Claude API を使うため `.env.local` の `ANTHROPIC_API_KEY` が必要です。生成には時間がかかります。

## デプロイ

Vercel に接続済みです。`main` に push すると自動でビルドと反映が走ります (2〜3分)。

環境変数は `ANTHROPIC_API_KEY` の1つだけ設定してください。

> 公開URLで読解とAI会話を使うと、利用者ぶんのAPI料金がキーの持ち主に請求されます。不特定多数に公開する場合は注意してください。
